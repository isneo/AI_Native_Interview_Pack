# AI Native 风控审核 Agent 面试叙事材料包

这是一套用于本地沉淀和持续迭代的面试准备材料。建议把它当成一个“小型知识仓库”，而不是一次性文档。

## 使用原则

1. **Markdown 做底稿**：所有核心观点、口播稿、追问回答先写成 Markdown，便于修改、搜索和版本管理。
2. **海报做训练卡**：每个章节最后压缩成一张高信息密度海报，用于复盘、分享和快速记忆。
3. **PPT/PDF 做对外版**：只有当底稿稳定后，再整理成 PPT 或 PDF。
4. **V2 做主线，V1 做支撑**：主叙事讲 AI Native 终局、审核体系重构、受控反馈与体系进化；细节用 V1 的业务痛点、技术实现和指标支撑。
5. **每次迭代留版本**：重大改动后，把旧版本放进 `06_归档与版本`，避免材料越改越乱。
