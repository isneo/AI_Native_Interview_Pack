# 00｜本地沉淀操作手册

## 一、最终沉淀形态

建议你本地保留四类资产：

```text
1. 章节底稿：Markdown
2. 训练材料：30 秒 / 2 分钟 / 5 分钟口播稿
3. 视觉材料：系列海报 PNG
4. 对外版本：PPT / PDF / 简历项目描述
```

核心原则：**先沉淀底稿，再压缩成海报，最后再做对外版本。**

---

## 二、本地目录怎么用

```text
AI_Native_Risk_Audit_Agent_Interview_Pack/
├── 00_总览/                # 总地图、操作手册、材料目录
├── 01_章节底稿/            # 每一章的正式内容
├── 02_海报素材/            # 海报 PNG、提示词、视觉版本
├── 03_口播训练/            # 30 秒、2 分钟、5 分钟口播稿
├── 04_追问答辩/            # 高频追问与回答模板
├── 05_汇报版本/            # PPT、PDF、分享稿
└── 06_归档与版本/          # 历史版本备份
```

---

## 三、推荐工作流

### Step 1：先维护章节底稿

每章都按这个结构写：

```text
1. 本章目标
2. 核心观点
3. 叙事框架
4. 面试口播
5. 图示逻辑
6. 高频追问
7. 回答模板
```

### Step 2：每章提炼一张海报

海报不是替代底稿，而是训练卡。建议每张海报只回答一个核心问题：

```text
海报 0：这个项目整体怎么讲？
海报 1：V1 和 V2 本质区别是什么？
海报 2：为什么要做 AI Native Agent 化？
海报 3：AI 原生风控审核体系由什么构成？
海报 4：Agent 如何完成一次审核？
海报 5：系统如何受控进化？
海报 6：技术模块如何支撑主线？
海报 7：价值怎么证明、面试怎么答？
```

### Step 3：再整理口播稿

口播稿不要一开始就写长。建议按三个长度训练：

```text
30 秒：讲定位
2 分钟：讲主线
5 分钟：讲完整项目
```

### Step 4：最后做对外汇报版

当章节底稿和海报稳定后，再做 PPT 或 PDF。否则容易陷入“版式很漂亮，但内容还没想清楚”的问题。

## 四、命名规范

建议使用：

```text
00_项目叙事总地图.md
04_结构化章节目录_v2.md
01_V1_vs_V2_叙事对比.md
02_核心矛盾与目标态.md
03_AI原生风控审核体系总架构.md
04_单次审核执行闭环.md
05_人机协同与体系进化闭环.md
06_技术模块如何支撑主叙事.md
07_价值指标与面试答辩.md
08_五条主线与三大支柱.md
```

海报命名：

```text
poster_00_项目叙事总地图.png
poster_01_V1_vs_V2_叙事对比.png
...
```

版本命名：

```text
v0.1_初稿
v0.2_补充口播
v0.3_补充答辩
v1.0_面试可用版
```

## 五、每次迭代时问自己三个问题

```text
1. 这版有没有更清楚地回答“这个项目为什么重要”？
2. 这版有没有既讲高度，也能落到具体实现？
3. 这版有没有准备好被面试官追问？
```
