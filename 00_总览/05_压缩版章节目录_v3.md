# 05｜压缩版章节目录 v3

## 压缩原则

主线章节只保留 5 章，对应五层叙事：

```text
1. 项目定位
2. 核心矛盾
3. 领域架构母图
4. 运行闭环
5. 技术支撑与价值证明
```

其他内容不删除，但降级为“校准材料”或“训练资产”：

```text
V1/V2 对比 → 前置叙事方法论
Claude 整合评估 → 外部材料吸收说明
口播 / 追问 / 海报 → 训练资产
```

## 推荐主线目录

### 前置｜叙事方法论

核心问题：

```text
为什么这套材料默认采用 V2 主线？
V1 为什么不废弃，而是作为支撑？
面试讲述和材料阅读的顺序有什么区别？
```

对应文件：

```text
01_章节底稿/01_V1_vs_V2_叙事对比.md
```

说明：这是材料阅读的前置方法论，但不是面试开场的第一段。面试时仍然直接从 V2 项目定位讲起。
