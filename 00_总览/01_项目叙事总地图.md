# 01｜项目叙事总地图（V2 主线版）

## 阅读定位

这份总地图默认采用 V2 主线，也就是从“风控审核业务域的 AI Native Agent 化”出发，而不是从“做了一个审核提效工具”出发。

建议先阅读 `01_章节底稿/01_V1_vs_V2_叙事对比.md` 作为叙事方法论，再进入这份总地图。V1/V2 对比不是用来反复选择主线，而是提前说明：为什么本资产包采用 V2 作为主叙事，V1 又如何作为业务痛点、技术实现和指标结果的支撑材料。

## 一句话定位

这个项目做的是**风控审核业务域的 AI Native Agent 化**。

它不是单点审核助手，也不是某个策略知识库，而是从未来风控审核体系的目标态出发，把审核中的知识、流程、工具、权限、证据和反馈机制，重构为 Agent 可理解、可调用、可约束、可解释、可评估、可进化的 AI 原生风控审核体系。

## 领域架构母图

### 五条主线

```text
1. 风险发现与识别
2. 审核研判与决策
3. 案件流转与处置编排
4. 知识沉淀与治理
5. 受控反馈与体系进化
```

五条主线回答的是：**整个风控审核业务域被拆成哪些对象来 Agent 化改造。**

### 三大支柱

```text
1. 审核域知识治理
2. 案件上下文与证据工具
3. Harness 约束与治理
```

三大支柱回答的是：**所有主线共享哪些底层能力，避免每条主线各造一套能力。**

### 三者关系

```text
总主线：为什么做，终局是什么
五条主线 × 三大支柱：领域怎么拆，能力怎么复用
运行闭环：系统具体怎么跑
```
