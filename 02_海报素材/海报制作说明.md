# 系列海报制作说明

## 系列名称

AI 原生风控审核体系面试叙事训练海报

## 海报体系定位

系列海报不是正文替代品，而是面试前的高密度训练卡。新版海报按“前置方法论 + 五层主叙事”组织：

```text
前置：V1/V2 叙事方法论
第 0 层：项目定位与总地图
第 1 层：核心矛盾与目标态
第 2 层：领域架构母图
第 3 层：运行闭环
第 4 层：技术支撑与价值证明
```

其中最重要的是领域架构母图，对应压缩版 `poster_02_领域架构母图_五条主线×三大支柱.png`。

## 每张主海报的视觉结构

```text
poster_M：
左右对比矩阵。左侧 V1：审核提效项目；右侧 V2：风控审核业务域 AI Native Agent 化。

poster_00：
五层纵向阶梯图。重点是“定位 → 矛盾 → 母图 → 闭环 → 价值”。

poster_01：
左侧展示割裂问题：规则、SOP、案例、经验、工具、反馈分散；右侧展示目标态六要素。

poster_02：
核心母图。上方目标态，中间五条主线，底部三大支柱，右侧反馈进化闭环。

poster_03：
左右双闭环。左侧单次审核：知识资产 → 上下文 → Agent → Harness → 证据链；右侧长期进化：人工反馈 → 归因 → 候选更新 → 验证 → 体系更新。

poster_04：
上半部分技术映射：RAG / Tool / Workflow / Harness / Eval / Observability；下半部分价值三层：短期提效 / 中期提质 / 长期进化。
```

| 海报 | 用途 | 内容 |
|---|---|---|
| poster_A_协同案例_新型风险事件处理链路 | 用一个案例串五条主线 | 风险发现 → 审核研判 → 流转处置 → 知识沉淀 → 体系进化 |

## 视觉原则

```text
白底 / 深色正文 / 蓝紫色主色
每张只回答一个核心问题
标题统一，结构统一，图示语言统一
海报是训练卡，不是正文替代品
```
